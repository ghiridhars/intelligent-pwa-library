# Data Schema Reference

All data in this system is stored as static JSON files served via GitHub Pages. There are two types of JSON files: the master catalog and per-book song indices.

---

## catalog.json

**Location:** `data/catalog.json`  
**Served at:** `https://username.github.io/library-manager/data/catalog.json`  
**Purpose:** Master list of all books. Loaded by the app on startup.

### Structure

`catalog.json` is a **JSON array** where each element represents one book.

```json
[
  {
    "book_id": "bhajanamritam_01",
    "title": "Bhajanamritam Vol. 1",
    "primary_language": "ml",
    "languages": ["ml"],
    "script": "malayalam",
    "type": "pdf",
    "index_file": "data/indices/bhajanamritam_01.json",
    "asset_url": "raw_assets/bhajanamritam_01.pdf",
    "page_count": 425
  }
]
```

### Field reference

| Field | Type | Required | Description |
|---|---|---|---|
| `book_id` | string | Yes | Unique identifier. Lowercase, underscores only. Used as the Hive cache key and in URL routing. Example: `bhajanamritam_01` |
| `title` | string | Yes | Display name of the book in English. Shown in the library catalog list. |
| `primary_language` | string | Yes | Language code of the dominant language. One of: `ml` (Malayalam), `ta` (Tamil), `hi` (Hindi), `sa` (Sanskrit). Determines which Tesseract language pack `ingest.py` uses. |
| `languages` | string[] | Yes | All languages present in the book. For single-language books this is `["ml"]`. For mixed books: `["ta", "sa"]`. |
| `script` | string | Yes | Writing system. One of: `malayalam`, `tamil`, `devanagari`. Used for font selection (future). |
| `type` | string | Yes | Currently always `"pdf"`. Reserved for future image-only book support. |
| `index_file` | string | Yes | Relative path to the book's song index JSON. Must match the output path used by `ingest.py`. |
| `asset_url` | string | Yes | Relative path to the PDF file in `raw_assets/`. Used by `PdfScreen` to construct the full download URL. |
| `page_count` | integer | Yes | Total number of pages. Shown in the book card and used as the upper bound for PDF navigation. |

### Adding a book

1. Add the PDF to `raw_assets/` via `git add` + `git commit`.
2. Add an entry to `catalog.json` (via Decap CMS or by editing directly).
3. Run `ingest.py` to generate the index (see [OCR Pipeline](ocr-pipeline.md)).
4. Review and commit the generated index file.

## Book index JSON

**Location:** `data/indices/<book_id>.json`  
**Served at:** `https://username.github.io/library-manager/data/indices/<book_id>.json`  
**Purpose:** Per-book song list. Loaded only when the user opens that specific book.

### Structure

A book index is a **JSON array** where each element represents one song.

```json
[
  {
    "song_id": "bhajanamritam_01_0188_anchel",
    "title_native": "അഞ്ചേൽ",
    "title_en": "Anchel",
    "language": "ml",
    "category": "Subrahmanyan",
    "page_number": 188,
    "tags": ["murugan", "kuntalavarali", "adi"]
  }
]
```

### Field reference

| Field | Type | Required | Description |
|---|---|---|---|
| `song_id` | string | Yes | Unique identifier within the book. Generated by `ingest.py` as `<book_id>_<page>_<slug>`. Do not change after committing — it is the Hive key used for future per-song features. |
| `title_native` | string | Yes | Title in the book's native script (e.g. Malayalam, Tamil, Devanagari). Extracted by OCR from the topmost text line on the page. **Review this field carefully** — it is the most common source of OCR errors. |
| `title_en` | string | No | English phonetic transliteration of the title. **Not generated by OCR** — must be filled in manually. Used for English-phonetic search (e.g. typing "Anchel" finds "അഞ്ചേൽ"). Leave as `""` if unknown. |
| `language` | string | Yes | Language code of this specific song. Same set as `primary_language` in catalog (`ml`, `ta`, `hi`, `sa`). Important for mixed-language books where individual songs may differ from the book's primary language. |
| `category` | string | No | Deity or subject category (e.g. `"Ganapati"`, `"Shiva"`, `"Rama"`). Shown as a chip in the song list. Used in search. Leave as `""` if not applicable. |
| `page_number` | integer | Yes | Physical page number in the PDF. Passed to `PdfScreen` to jump directly to the song. 1-based (page 1 = first page). |
| `tags` | string[] | No | Searchable keywords: raga, tala, deity names, festival occasions, etc. All lowercase. Used by `SearchService` — searching "adi" returns all songs tagged with `"adi"`. |

### Search behaviour

`SearchService` combines all fields into a single searchable string:

```
{title_native} {title_en} {category} {tags joined by space}
```

A query matches a song if every word in the query appears somewhere in that string (case-insensitive). Results are ranked: title prefix matches score highest, then title substring, then category/tag matches.

### Mixed-language books

For a book containing both Tamil songs and Sanskrit verses, each entry carries its own `language` field:

```json
[
  { "song_id": "...", "language": "ta", "title_native": "முருகா", ... },
  { "song_id": "...", "language": "sa", "title_native": "गणपतिम्", ... }
]
```

The `languages` array in `catalog.json` declares all languages present: `["ta", "sa"]`.

## Language code reference

| Code | Language | Script | Tesseract pack |
|---|---|---|---|
| `ml` | Malayalam | Malayalam | `tesseract-ocr-mal` |
| `ta` | Tamil | Tamil | `tesseract-ocr-tam` |
| `hi` | Hindi | Devanagari | `tesseract-ocr-hin` |
| `sa` | Sanskrit | Devanagari | `tesseract-ocr-san` (or `hin`) |

Hindi and Sanskrit share the Devanagari script. Either language pack produces usable OCR output for both.

## File size guidelines

| File | Recommended max | Reason |
|---|---|---|
| `catalog.json` | 50 KB | Loaded on every app startup |
| Single book index | 500 KB | Loaded into memory for search; larger files slow the initial book open |
| Single PDF | 50 MB | GitHub file size limit is 100 MB; 50 MB keeps GitHub Pages delivery fast |
| Total repo | 1 GB | GitHub Pages soft warning threshold |
